Starbie

Starbie is a virtual pet powered by a Seeed XIAO ESP32-C3, with an OLED display, motion sensing, and temperature/humidity readings. It also works as a Bluetooth macropad.

Features

Virtual pet with Joy, Energy, and Fullness stats

Motion-based interactions and pet activities

Bluetooth shortcuts for Copy, Paste, Cut, Undo, and Screenshot

Switch between pet and macropad modes using D2

Hardware: XIAO ESP32-C3, OLED, MPU6050, DHT11, and six buttons.

Libraries: Adafruit SSD1306, Adafruit GFX, MPU6050, DHT, and a compatible BLE Keyboard library.
